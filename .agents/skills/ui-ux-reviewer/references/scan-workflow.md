# Scan Workflow（执行细节）

## FE Card 模板

```markdown

- 前端根：…
- 框架 / 包管理：…
- UI 库 / Token：…
- 路由入口文件：…
- 菜单/侧栏配置：…
- 锁定标杆页：…（只读）
- 已有共享壳：PageHeader=… · 列表壳=… · 空态=… · KPI=… · 表单壳=…（无则写「待 W1 抽取」）
- 响应式承诺：桌面 only / 含平板 / 含移动
- 主题：无 / 有 dark 开关
- RBAC 表面：无 / 有（角色或权限码）
- 设计 skill：有/无（名称）
- 范围：整前端 / 域：… / 排除：…
- 产品文案语言：简体中文 / …
- API 纪律：本仓 codegen 命令与禁止手改路径（无则写「无强制 codegen」）
- 建议并行：按域 … 或按菜谱 …；复用审计：按菜谱分组
```

## 路由勾选

1. 从路由表提取 path + 懒加载/组件名。  
2. 对照侧栏/菜单：有菜单无路由、有路由无菜单 → 记 P1（入口漂移）。  
3. 排除：login/callback、redirect-only、dev playground（若用户确认非产品）。  
4. 勾选表状态机：`待扫` → `通过` | `fail` | `延期`。

PR/变更面模式：主根 = diff 目录；仍须列出**受影响路由**全集，并对同菜谱邻页抽 1 个对照，防只修一页风格更碎。

## 复用审计 Subagent（可与域扫并行）

```text
你是只读「组件复用」审计 agent。不要改代码。
项目根：{ROOT}
FE Card 共享壳清单：{…}
菜谱分组与页面文件：{来自勾选表}
按 component-reuse.md 判定门槛回传「复用审计」块。
禁止把不同菜谱的正当差异报成未复用。
```

## 并行与波次

| 规模 | 做法 |
|------|------|
| 少于约 15 路由 | 主 agent 可串行；仍填勾选表 |
| 中型 | 按域 2～4 个 explore 并行 |
| 大型（50+） | W1 共享壳结论 → W2 分域并行 → W3 API/延期清单 → W4 抽检毕业 |

共享组件文件锁：W2+ 禁止多代理同时改同一共享 path；共享变更单独批次。

## 与契约 / 后端

- 发现页要字段但 API 无：P1「缺契约」；允许**延期**并写进报告附录。  
- **禁止**用 mock 列表/假 KPI 混过毕业。  
- 若仓有 codegen（如 openapi、goctl、orval）：修 API 时遵守仓内文档；禁止手改标明的生成文件。

## 修复批次（确认后）

| 批次 | 内容 |
|------|------|
| S0 共享壳 | Header/列表壳/空态/Token；**含应复用未复用的抽取与改引用**；串行 |
| S1…Sn 分域 | 按勾选 fail 页；一域一代理或一菜谱一代理；须 import S0 结果 |
| API | 仅用户确认的契约项；跟本仓纪律 |
| 回归 | 反模式 rg + 同菜谱抽检 ≥2 页 + 标杆目视/截图 + 相关单测 |

完成定义：该批路径反模式清零或改「延期」；同构页已复用共享壳；**实现与已确认 RP 改造方案一致**（偏离须说明）；标杆无回归；勾选表更新。
